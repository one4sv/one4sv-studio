**Ветка `main` — источник истины.** Вся техническая документация — в `docs/`, по примеру AT. При расхождении с текстом сначала проверить исходный код.

- [Дизайн](DESIGN.md) — бренд, цвета, логотип и скриншоты.

## Договорённости

- Бренд — **one4sv.studio** (строчные буквы, с точкой), акцент на `4sv.`.
- Проекты — **Achieve Together** и **Localhost Manager**.
- Скриншоты показываются целиком: `object-fit: contain`.
- Буква `4` чуть выше остальных, но низ на той же базовой линии; между `e` и `4` есть зазор.
- Тема `auto` реагирует на настройки браузера; ручной выбор через выпадающий список.
- На сайте нет аутентификации oneAcc или серверной логики.

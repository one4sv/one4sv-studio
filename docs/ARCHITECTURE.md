# Архитектура сайта one4sv.studio

Сайт — React 19 + TypeScript, Vite 7, SCSS. Статический SPA без серверной авторизации. Основная точка входа — src/main.tsx, композиция главной страницы и UI-компоненты — src/App.tsx, стили — src/styles.scss. Структуру проекта менять только под конкретные задачи.

## Экраны и компоненты

- Header — навигация, ссылка на GitHub, меню темы.
- Brand — единый логотип с общей базовой линией; четвёрка визуально выше благодаря размеру, а не вертикальному смещению.
- ProjectSection — одно оформление обеих витрин, одинаковые кнопки «Открыть проект» и «Исходный код».
- Gallery — просмотр скринов с объектом изображения целиком (object-fit: contain), стрелками и счётчиком.
- ImagePreview — React-портал полноэкранного просмотра; сведения о проекте и технологиях, клавиши Escape, ←, →.
- FutureSection, AboutSection и Footer — информационные блоки студии.

Картинки и favicon размещаются в public/assets. При смене исходных скриншотов не обрезать их физически.

Данные проектов и изображений локальны в src/App.tsx, без внешних запросов и аутентификации. Сайт поддерживает тему браузера через prefers-color-scheme и ручное переопределение в localStorage.

Иконки проектов хранятся локально в `public/assets/`: AT — `at-icon.svg`, Localhost Manager — `localhost-manager-icon.png` (оригинальная PNG-рамка из `.ico`). Не загружать иконки с GitHub Raw в рантайме.

# Регрессионные проверки

1. Открыть сайт на ПК и телефоне; проверить отсутствие горизонтальной прокрутки.
2. Проверить логотип: общая нижняя линия у `4`, промежуток `e4`, отсутствие движения при курсоре.
3. Выбрать «Авто / Тёмная / Светлая» в выпадающем списке; клик вне и Escape закрывают меню.
4. Сменить системную тему с «Авто» и проверить реакцию страницы.
5. Пролистать три скрина Achieve Together, открыть полноэкранный просмотр, проверить отсутствие обрезки и центрирование стрелок.
6. Проверить наличие целого скриншота Localhost Manager.
7. Открыть AT GitHub, Localhost Manager GitHub и releases.
8. Проверить отсутствие 404 для CSS/JS/изображений.

Минимальная проверка синтаксиса: `node --check js/app.js`. Она не заменяет браузерный QA или подтверждение Vercel READY.

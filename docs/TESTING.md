# Проверки сайта

1. Проверить Vite production build: npm run build.
2. Открыть главную на ПК и телефоне — макет без горизонтального прокручивания.
3. Проверить логотип: 4 выступает вверх, нижняя линия символов совпадает, e и 4 разделены.
4. Проверить выпадающий список темы: Авто, Тёмная, Светлая, сохранение выбора и реакцию Авто на системную тему.
5. Проверить переходы в оба проекта, на исходный код, кнопки не перепутаны.
6. В обеих галереях скриншоты целиком — без CSS обрезки; Localhost Manager раскрывается по нажатию.
7. В полноэкранном просмотре проверить стрелки, счётчик, описание/технологии, закрытие Escape и по крестику, блокировку прокрутки фона.
8. Проверить ссылки и локализацию на мобильном экране.
9. После публикации сверить GitHub commit SHA с production deployment Vercel.\n10. Проверить реальный favicon AT и icon.ico Localhost Manager в карточках, центрирование SVG-стрелки темы и нормальный значок GitHub.\n11. Проверить обновлённый скрин активности в обеих галереях, включая масштабирование на мобильных экранах.

12. Проверить крупный логотип мышью: движение точки вдоль орбиты, плавное смещение всей надписи и возврат при уходе курсора. `4` остаётся на общей базовой линии, подсказка «двигай курсором» не отображается.
13. Проверить `prefers-reduced-motion`: орбита статична; касания на мобильном не вызывают смещение логотипа.

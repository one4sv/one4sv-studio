# Визуальные правила

Бренд пишется строго как one4sv.studio — строчными буквами, с точкой, акцент 4sv. ярко-зелёный. Символ 4 выше остальных, однако базовая линия текста общая. Между e и 4 нужен видимый интервал. Декоративная орбита статична, приглашение «двигай курсором» не используется.

Цвета: светлая тема с нейтральным почти белым фоном; тёмная с нейтральным угольным фоном, без зеленовато-серых панелей. Акцентный цвет используется умеренно. Переключатель темы — выпадающий список Авто / Тёмная / Светлая.

Подписи и кнопки должны быть читаемыми: мелкие подписи, техстек, данные галереи и мобильные кнопки увеличены. Иконки проектов используются из оригинальных репозиториев (AT favicon SVG и Localhost Manager icon.ico). Шеврон темы — SVG, а не шрифтовой символ. Витрины Achieve Together и Localhost Manager получают идентичную композицию и две одинаково названные кнопки.

Изображения: исходники в public/assets, отображать целиком через object-fit: contain, без background-size: cover. Полноэкранный React-просмотр показывает название, описание и технологии проекта. Переключение изображений — только стрелки, без текста «назад» и «дальше».

Не помещать техническую документацию в корневой README: он описывает студию от первого лица.

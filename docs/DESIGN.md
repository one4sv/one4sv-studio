# Дизайн-система

## Логотип
`one4sv.studio` пишется строчными буквами и с точкой. Кислотно-зелёный — только `4sv.`. Буква `4` чуть выступает сверху, но находится на общей нижней линии с остальными символами. Между `e` и `4` нужен достаточный зазор. Орбита — статичный декор; не добавлять «двигай курсором» и эффект перемещения мышью.

## Палитра
Светлая: фон `#f6f7f5`, панели белые. Тёмная: нейтральный графит `#111213`, панели `#191a1c`, второй слой `#202123`. Не использовать нежелательные оттенки `rgb(32,37,32)` и `rgb(28,32,28)`. Акцент — яркий зелёный.

## UI
- Скрины в галерее: полное изображение, `object-fit: contain`, без обрезки.
- Стрелки в круглых кнопках: SVG, центрировать по обеим осям.
- Темы: выпадающий список «Авто / Тёмная / Светлая».
- Мобильная вёрстка: одна колонка для разделов продуктов.
- Избегать неонового свечения и лишних эффектов; поддерживать `prefers-reduced-motion`.

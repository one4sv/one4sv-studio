# one4sv.studio

Готовый статический сайт студии one4sv в минималистичном стиле. Без сборщика и внешних JS-зависимостей.

## Как запустить

Откройте `index.html` двойным кликом. Для проверки через локальный HTTP-сервер:

```bash
python -m http.server 5173
```

Затем откройте `http://localhost:5173`.

## Что сделано

- Адаптивная главная страница на русском языке.
- Логотип **one4sv.studio**: строчные буквы, выступающая `4`, акцент на `4sv.`, курсор управляет тонкой орбитой и подъёмом четвёрки.
- Автоматическое переключение светлой/тёмной темы по настройкам браузера; ручное переключение **авто → тёмная → светлая** в шапке, сохранение выбора в `localStorage`.
- Навигация по секциям AchieveTogether, Localhost Manager и будущие проекты.
- Галерея из трёх **реальных скриншотов AT**: вкладки, стрелки, модальный просмотр, управление клавиатурой.
- Скриншоты обрезаны по основному контенту, чтобы не публиковать личные сведения и списки контактов из боковых панелей.
- Accessibility: ссылки пропуска, видимый focus, alt, ARIA, системная поддержка reduced motion.
- SEO-метаданные, favicon SVG.

## Файлы

- `index.html` — структура страницы;
- `css/style.css` — все стили;
- `js/app.js` — интерактивность;
- `assets/at-*.webp` — изображения AchieveTogether;
- `assets/favicon.svg` — иконка.

## Размещение на Vercel

1. Создать репозиторий и загрузить содержимое этой папки (или импортировать архив после распаковки).
2. Импортировать репозиторий в Vercel как **Other** / статический сайт.
3. Build Command оставить пустой, Output Directory оставить `.` (корень проекта).
4. Подключить домен `one4sv.studio` после настройки DNS в регистраторе.

Сайт не содержит подключённого бэкенда oneAcc, входа или базы пользователей. Для Localhost Manager показан **концепт**, а не реальный скриншот приложения.

Если понадобится размещение без запросов к Google Fonts, замените импорт Manrope в `css/style.css` на локально установленный системный шрифт; сайт уже имеет подходящий запасной стек.
